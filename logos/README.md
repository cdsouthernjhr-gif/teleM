# Logos

Put channel logos here (PNG, ≤300 KB, ~256×256, transparent background), one folder per country, then set the channel's `logo` field, e.g. `"logo": "logos/malaysia/tv1.png"`, and bump the database version.

Only add logos you are allowed to use (broadcaster press kits or written permission). Until a logo is added, the app shows a generated monogram tile.

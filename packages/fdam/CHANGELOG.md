## 1.0.0

* First release of the Flutter Dynamic Asset Manager: manifest reader with
  ETag cache and strict validation, Dio download engine (priority queue,
  Range resume with If-Range, pause/resume/cancel/retry, backoff), SHA-256
  verification, safe ZIP extraction, staged install with backup/rollback and
  crash recovery, SQLite metadata with migrations, version planner,
  network policy, WorkManager maintenance, Riverpod UI (Malay/English).
